docx文档修改说明

参照修改以下事项后，文档可转换出法务条款类似的页面

替换项目列表
文档中的“1. ” “1.13"项目编号需要替换成文字
页面标题可以使用word中的样式2
例如：“儿童隐私保护指引”
页面中的一级和二级标题使用样式3
例如：“1. 或 1.2 ”
文档末尾的落款使用样式"author"
例如：“深圳市腾讯计算机系统有限公司”
文档增加红色样式"red"
常见问题：1：文档中有"?"
通常是docx内有无法识别的空格导致
常见问题：2：链接点开后无法正常显示
具体现象为：chrome地址栏显示的并不是word中配置的链接，后面带一对其他字符?
原因：通常是因为word中配置链接时将"要显示的文本"这一栏包含了中文的“《”
解决办法：删除“有问题的”超链接，并重新选择中括号内的文字创建链接
